# 实现状态清单（已实现 / 未实现 / Mock / 风险）

> 测试基线：`python -m pytest tests/ -q` → **33 passed**（2026-11-23）

## ✅ 已实现（含服务层规则/事务/权限/测试）

| 域 | 内容 |
|---|---|
| auth | 注册/登录/刷新轮换/**复用检测撤链**/登出/会话管理/Argon2id/TOTP-MFA(仿真码) |
| users | 资料、收货地址 CRUD |
| rbac | 权限目录+5类管理角色种子、角色授予/移除、超管通配、**店铺角色四级限权（多店铺身份）** |
| merchants/stores | 入驻申请→审核（自动建店+店主）→冻结/解冻；店铺资料、员工管理、工作台统计 |
| catalog | 商品/SKU/图片 CRUD、**审核状态机**、上下架、分类、图片上传（MIME+魔数+大小校验）、消费者检索 |
| inventory | **条件 UPDATE 并发防超卖（已测 20 线程）**、预占/释放/出库/超时释放、全部变更流水 |
| cart | 加购/改量/勾选/删除，价格库存实时服务端 |
| orders | **服务端计价预览（运费/绿豆抵扣）、多商家拆父/子单、快照、PRICE_CHANGED 防篡改、幂等键、取消释放、发货消耗库存、确认收货发绿豆、状态机+迁移日志** |
| payments | Provider 抽象、**Mock 沙箱（HMAC 验签/金额币种核对/trade_no 幂等）**、重复回调 duplicate 应答、退款申请/审核/Mock 原路退回 |
| logistics | 发货单+轨迹（Mock 数据）、消费者查询 |
| points | 独立账户、规则版本化、幂等流水、订单发放/退款比例冲正、管理员调整（必填原因+审计）、兑换（Mock 权益） |
| cms | 页面/区块、**组件白名单+Pydantic 强校验**、预览、发布（不可变快照版本）、回滚、公告、Banner、客户端配置（ETag、未知组件安全降级） |
| aid | 合作社、助农项目 CRUD+发布审核、消费者浏览 |
| green | 绿色资料提交/审核、碳评估（**默认未核验标记**）、核验记录 |
| finance | 平台账（支付/佣金/退款只追加流水）、结算单生成/确认/打款（状态流转）、商家汇总 |
| audit | 操作日志/登录日志/安全事件，敏感操作全落审计 |
| admin | 仪表盘、系统设置、用户封禁（撤销全部会话）、各域管理端 |
| 基础设施 | 统一响应/错误码、request_id、JSON 日志、限流（Redis/内存）、CORS、健康探针、Docker/Compose、.env.example、Alembic 迁移、种子数据 |

## ⚠️ 风险与已知限制

| # | 风险 | 说明/缓解 |
|---|---|---|
| 1 | **业务参数全部为仿真值** | 上线前必须逐项确认 pending-decisions.md 20 项 |
| 2 | 沙箱支付工具在生产禁用 | `/payments/mock/pay` 已按 ENV=prod 拒绝 |
| 3 | SQLite 开发库关闭 fsync 提速 | 仅影响开发库（网络盘优化）；生产 PostgreSQL 不受影响 |
| 4 | 限流为进程内存（未配 Redis 时） | 多实例部署必须配置 TANHUI_REDIS_URL |
| 5 | 结算口径假设（不含运费） | 业务确认佣金基数后调整 finance service |
| 6 | Celery 未配置时任务同步执行 | 长事务（如批量结算）生产建议配置 broker |
| 7 | JSONB 在 SQLite 退化为 JSON | 类型适配层已处理；生产 PG 原生 JSONB |
| 8 | 上线合规 | 涉及支付/个人信息/商家资质，需安全、隐私、支付合规与业务规则审核（派发包重要提醒） |
